Room for your next game. Tell Claude the idea and it gets added here.

Adding a game

  • One game, one scene. Each game is a Phaser scene registered with registerGame.
  • Everything draws from code. The starters build their art with shapes, so there are no image files to manage.
  • The shelf updates itself. A registered game gets its own button and a link you can share, like #my-game.
registerGame({
  id: 'my-game',            // letters, digits and hyphens
  title: 'My Game',
  blurb: 'One line about how it plays.',
  controls: 'Arrow keys to move',
  scene: class MyGame extends Phaser.Scene {
    create() {
      this.player = this.add.rectangle(320, 200, 32, 32, 0x86a4ff);
      this.cursors = this.input.keyboard.createCursorKeys();
    }
    update(time, delta) {
      const dt = delta / 1000;
      if (this.cursors.left.isDown)  this.player.x -= 240 * dt;
      if (this.cursors.right.isDown) this.player.x += 240 * dt;
    }
  }
});
